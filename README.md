# Aventuras em Brusque

Jogo educativo infantil sobre a cidade de Brusque.

## Tecnologias
- HTML
- CSS
- JavaScript
- Java

## Funcionalidades
- Perguntas educativas
- 4 alternativas
- Sistema de pontuação
- Personagens infantis
- Interface colorida

## Como executar
1. Abra o arquivo index.html no navegador.
2. Responda as perguntas.
3. Veja sua pontuação final.
